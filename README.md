# Adam Fit

Adam Fit — персональный фитнес-помощник для тренировок, питания и контроля прогресса.

**Your plan. Your progress. Your fit.**

## Project IDs

- App name: `Adam Fit`
- Android package name: `com.adamfit.app`
- Firebase project: `adam-fit-5ec39`
- GitHub Pages: https://unnamed00000.github.io/Adam-fit/

## MVP

This repository contains the first installable web/PWA MVP:

- splash screen;
- email registration and login flow with local fallback;
- onboarding profile setup;
- goal selection and daily calorie/protein/water/step calculation;
- Today dashboard;
- manual food logging;
- water and step tracking;
- personalized weekly workout plan;
- guided workout session with sets and rest timer;
- weight logging and chart;
- profile/settings;
- Russian, English, and Danish UI strings.

Firebase Hosting is configured for `adam-fit-5ec39`. Real Firebase Auth/Firestore/Storage can be connected from the included service layer once the Firebase web app config and product rules are active.
